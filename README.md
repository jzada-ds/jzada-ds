## Featured Projects
Full case studies are on [jonathanzada.com](https://jonathanzada.com/#projects).

**[Used Car Price Analysis & Prediction](https://github.com/jzada-ds/data-projects/tree/main/used-car-price-analysis)** · [Case study](https://jonathanzada.com/work/used-car-prices)  
Exploratory analysis and price prediction on 10,000 used-car records, from bootstrap group comparisons to KNN classification and linear regression.
- **Stack:** Python, Pandas, NumPy, scikit-learn, Matplotlib, Seaborn
- **Result:** R² 0.877 on the test set (RMSE $989.82 vs. $2,821.77 for a mean-price baseline), graded 100/100

**[Econometrics: Panel Data Analysis](https://github.com/jzada-ds/data-projects/tree/main/panel-data-analysis)** · [Case study](https://jonathanzada.com/work/panel-data-analysis)  
A panel-data study of whether shall-carry laws are associated with violent-crime rates across 51 US jurisdictions from 1977 to 1999.
- **Stack:** R, plm, nlme
- **Result:** Random effects chosen with a Hausman test, with inference corrected using state-clustered standard errors across 1,173 observations

**[Football Transfer & Performance Simulator](https://github.com/jzada-ds/football-fantasy)** · [Case study](https://jonathanzada.com/work/football-simulator) · [Live demo](http://footfan.israelcentral.cloudapp.azure.com/)  
A squad-management web app where transfer and lineup decisions are tested by an ML match-simulation engine. Team project.
- **Stack:** Flask, scikit-learn, MongoDB, React, Docker Compose, Nginx, pytest
- **Result:** Four Docker services with model inference in its own service, covered by 119 passing tests

**[Clinic Queue Manager](https://github.com/jzada-ds/data-projects/tree/main/clinic-queue-manager)** · [Case study](https://jonathanzada.com/work/clinic-queue-manager)  
Clinic queues, early departures, and workload statistics in logarithmic time, built on four coordinated 2-3 tree indexes. Team project.
- **Stack:** Java, augmented 2-3 trees, subtree aggregates
- **Result:** 34,450/34,450 random operations passed in official grading, graded 100/100
